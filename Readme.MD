# Bare Metal HTTPS Flask Password Project
This is an example project for the Raspberry Pico 2W that demonstrates  
use of HTTPS for retreiving a 6 character password string from a Python Flask  
web server.

## secrets.h
#define WIFI_SSID     "YourWiFiSSID"
